# CFOmatics

Next.js + Tailwind CSS conversion of the CFOmatics editorial site.

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home |
| `/article` | Article detail |
| `/topic` | Topic listing |
| `/resources` | Resource library |
| `/about` | About |

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js App Router
- Tailwind CSS v4 (design tokens in `@theme`)
- Google fonts via `next/font` (Newsreader, Inter, IBM Plex Mono)
